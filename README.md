# Python Basics

Практична робота №1 з дисципліни ВМПтФ — основи Python, 4 рівні складності.

- **level1.py** — базові конструкції: виведення чисел, привітання, сума, пошук найменшого
- **level2.py** — цикли та алгоритми: середнє значення, квадрати чисел, перевірка на просте число, обернення рядка
- **level3.py** — ООП і обробка даних: розрахунок віку, фільтрація парних чисел, клас Calculator, перевірка на паліндром
- **level4.py** — складніші класи та алгоритми: Book/Library, робота з API (`requests`), QuickSort

## Запуск
```bash
pip install requests
python3 level1.py
python3 level2.py
python3 level3.py
python3 level4.py
```
